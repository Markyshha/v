PANORAMA VR
===========

Что это:
Локальная VR-галерея для панорамных фотографий.

Запуск:
1. Запусти START_HERE.bat.
2. На компьютере открой:
   http://localhost:8000
3. Перетащи в окно JPG/JPEG/PNG панорамы.
4. Нажми "Войти в VR".

Управление:
- Головой осматриваешь панораму.
- Правый контроллер Quest:
  A = следующая панорама
  B = предыдущая панорама
- На ПК:
  стрелка вправо / A = следующая
  стрелка влево / B = предыдущая

ВАЖНО ПРО QUEST:
WebXR требует защищённого контекста для обычного сетевого доступа.
http://localhost работает на компьютере, но адрес вида
http://192.168.x.x:8000 на Quest может не дать войти в VR.

Для Quest удобнее открыть сайт через HTTPS-сервер в локальной сети
(например, с mkcert или другим локальным сертификатом).

Панорамы:
Лучше всего подходят настоящие 360° equirectangular изображения
с соотношением сторон 2:1, например 6000x3000 или 4096x2048.
Обычная фотография тоже откроется, но вокруг неё будут пустые области.

Файлы:
index.html — страница
style.css  — внешний вид
app.js     — VR, панорама и контроллеры
START_HERE.bat — локальный сервер

Интернет:
Three.js загружается из jsDelivr при открытии страницы.
То есть для первого запуска нужен интернет.
